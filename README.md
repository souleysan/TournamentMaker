# 🇫🇷 Gestionnaire de Tournois sportifs
<br>

### Gestionnaire de poules/tableaux pour tournois sportifs

L'idée sera de pouvoir entrer les nom, prénom, catégorie d'âge et poid des participants, afin de faciliter la création des groupes de compétition.
Plusieurs onglets seront prévus pour différentes vues à sovoir :

- **(ONGLET)** - Vue de tous les participants
    - **(MENU DÉROULANT)** Séparation filles/garçons

- **(ONGLET)** - Vue sur les inscriptions par club

- **(ONGLET)** - Vue sur les inscriptions par catégorie (s'il y en a plusieurs)

- **(ONGLET)** - Vue des différentes poules/tableaux générées

- **(ONGLET)** - Vue par résultats à la fin de la compétition


On prévoit également d'autres fonctionnalités :
- Sauvegarde des entrées - **sous forme de fichier (structure et format à voir ultérieurement)**
- Sauvegade des goupes - **sous forme de fichier (structure et format à voir ultérieurement)**

# 🇬🇧 Sports tournament Manager
<br>

### A sports group manager 

The idea is to be able to enter participant's name, fisrtname, age category and weight class, to create competition groups easier.
Many tab are are here for different views :

- **(TAB)** - All participants view
    - **(DROP-DOWN MENU)** Possibility to separate girls from boys

- **(TAB)** - Clubs registrations view

- **(TAB)** - Weight class registrations view (if there are a lot of them)

- **(TAB)** - Generated groups view

- **(TAB)** - Participants results view


We expect also others features :
- Entries' saves - **by files (structure and format to decide)**
- Created groups' saves - **by files (structure and format to decide)**
